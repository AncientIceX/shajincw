# 砂金小狐狸桌宠 (shajincw) v3.0 · 治愈系 UI 与探头收纳升级版

基于《崩坏：星穹铁道》砂金小狐狸/猫猫糕透明 PNG 打造的 **Windows 桌面宠物 + 拖拽文件快捷后缀重命名工具**。

## v3.0 核心升级特性

### 1. 日系治愈低饱和 UI 设计语言
- **配色体系**：奶油白 (`#FDFAF3`)、浅薄荷绿 (`#DAF2EC` / `#7CC6B8`)、香槟金 (`#ECCE94`)、柔和紫 (`#B28ED0`)、深棕紫正文 (`#523A42`)。
- **环绕式小圆形矢量图标按钮**：悬停或点击小狐狸时，身侧以 220ms 淡入+微缩放展开 5 枚统一线条粗细的小圆形矢量按钮（喂食、喝水、玩耍、铲屎、改名）与底部磨砂胶囊状态条；非交互状态 1.6s 后自动淡出隐藏，保持桌面干净整洁。
- **防越界边缘自适应**：小圆形按钮、弹出式食物菜单、头顶小巧圆角对话气泡均根据当前显示器左右/顶部边界自动调整展开方向，绝不超出屏幕。
- **精准透明区域鼠标穿透 (`QBitmap` 动态掩码)**：只有狐狸本体与可见 UI 胶囊接收点击，周围透明区域 100% 穿透到底层桌面图标与窗口。

### 2. 单张 PNG 程序化动画与优先级状态机
- **严格状态优先级**：`文件拖放 > 手动拖动 > 喂食互动 > 单击反馈 > 探头收纳 > 待机动画`，彻底消除多动画争夺坐标与形变冲突。
- **待机微动作**：极小幅度呼吸浮动 + 随机间隔（5.5~12s）触发轻微歪头、伸展或轻弹。
- **悬停与单击**：悬停 200ms 自然缓动抬起并放大 3%；单击轻柔压缩回弹并飘出 3~5 颗低饱和小爱心/四角星/香槟金微光粒子。
- **拖拽物理反馈**：跟随鼠标移动方向产生柔和倾斜角（限制在 ±9° 内），松开后平滑阻尼回弹。
- **自适应帧率节能**：交互与动画期 60FPS 丝滑渲染，静止待机期自动降至 24FPS 降低 CPU 占用。

### 3. 弹出式精致食物菜单 & 6 阶段顺序喂食动画
- 点击喂食圆形按钮，在狐狸身旁弹出磨砂小食物菜单（金珀蛋挞、薄荷奶油糕、星光蜜桃茶、焦糖猫爪冻）。
- 点选食物后按严格时间轴播放 6 阶段连贯动画：
  1. 食物从菜单位置轻轻浮起；
  2. 沿二次贝塞尔曲线飞向狐狸嘴边；
  3. 狐狸微微前倾迎接食物；
  4. 食物在嘴边逐渐缩小并淡出（被吃掉）；
  5. 狐狸开心轻轻弹跳，飘出柔和星心粒子；
  6. 弹出「好吃～」「谢谢款待！」「再来一点？」等小巧气泡，并将食物计入肠胃消化系统（消化满 100% 后排便）。

### 4. 屏幕底部自动吸附与两段式探头收纳
- **磁吸与原尺寸下沉裁剪**：拖动狐狸接近当前显示器工作区底边（任务栏上方 30~50px）时产生磁吸提示线；松开鼠标后（480ms `ease-in-out`）保持狐狸原有尺寸整体向下沉入屏幕底边之外，仅露出耳朵与上半颗脑袋观察主人。
- **两段式悬停探头**：鼠标移到露出的半颗脑袋上时，小狐狸先向上轻探一点（180ms） -> 短暂停顿观察（140ms） -> 再完整探出身体（460ms `ease-out-back`）。
- **自动沉回与随时中断**：鼠标移开后延迟 1.45s 慢慢沉回底部；下沉途中若鼠标再次靠近可随时中断并重新展开；展开后可直接拖走退出底部吸附状态。
- **右键控制**：支持「开启/关闭底部自动探头收纳」「固定展开（不自动沉回底部）」。

### 5. 文件拖放添加后缀（安全防覆盖）
- 拖动文件靠近狐狸时：狐狸轻微抬起 + 浮现柔和香槟金虚线光环 + 弹出「交给我吧～」气泡。
- 松开文件后：唤出纯白圆角胶囊长条输入框，输入如 `555` 按回车，原地重命名为 `000（555).jpg`。
- 支持单文件与批量拖放，自动拦截非法文件名字符与同名文件冲突（绝不无提示覆盖已有文件）。
