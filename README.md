# 住在桌面上的小狐狸 (shajincw) v4.0

基于《崩坏：星穹铁道》砂金小狐狸透明原画打造的 **Windows 桌面陪伴宠物 + 极简文件后缀重命名工具**。

## v4.0 核心升级特性

### 1. 1:1 复刻「奶油白 · 浅薄荷绿 · 香槟金」轻拟物 UI
- **横向全圆角胶囊工具栏**：悬浮于小狐狸正下方，包含 4 个极简线性图标：
  - `🍴` 喂食：弹出「今天想吃点什么？」1×4 点心卡片
  - `Aa` 改名：打开「把文件交给我」重命名面板
  - `⊻` 收纳：立即沉入屏幕底部边缘进入探头观察模式
  - `···` 更多：展开**无级大小调节滑块（25% ~ 150%）**与饱食状态面板
- **「今天想吃点什么？」1×4 横向点心面板**：
  - 包含 **小饼干、三文鱼、甜桃子、热可可** 4 款手绘风点心，点击后沿二次贝塞尔曲线飞向嘴边被吃掉，计入真实肠胃消化排便循环。

### 2. 滑块无级调大小 + 超小巧迷你尺寸支持
- 点击胶囊工具栏的 `···` 即可直接拖动横向滑块实时无级调节小狐狸大小（或按住 `Ctrl + 滚轮`）。
- 下限缩至 **25%（约 42px 迷你桌面小挂件）**，默认尺寸也更加精致小巧，不挡屏幕。

### 3. 「把文件交给我」极简文件重命名
- 把任意文件（单个或多个）拖到小狐狸身上，弹出「把文件交给我」卡片：
  - **极简直接追加规则**：在输入框里输入什么，就直接加在原文件名（不含扩展名）后面！
  - 例如原文件 `000.jpg`：输入 `(555)` 变成 `000(555).jpg`；输入 `_v2` 变成 `000_v2.jpg`；输入 `555` 变成 `000555.jpg`。
  - 下方实时展示「原文件名」与「改名后」双列对比预览，点击浅薄荷绿「确认改名」按钮或按回车即可原地更新。
