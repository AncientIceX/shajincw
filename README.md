# 砂金猫猫桌面宠物 (shajincw)

基于《崩坏：星穹铁道》砂金猫猫糕形象打造的 **Windows 桌面宠物 + 拖拽文件快捷后缀重命名工具**。

## 核心功能
- **全透明置顶桌宠**：Q弹呼吸动画、点击跳跃、桌面自由散步、系统托盘常驻。
- **丰富养成互动**：
  - `🍖 喂食`（黄金猫糕/鱼子酱，恢复饱食度）
  - `🧋 喝水`（冰镇特调，恢复水分）
  - `🎲 玩耍`（掷砂金骰子/筹码，恢复心情）
  - `💩 拉屎与铲屎`（吃饱后或定时会在地板拉便便，可直接点击便便或点「铲屎」按钮清理）
  - `💬 自主说话 & 点击随机语音气泡`：饿了、渴了、无聊了、嫌地板脏了都会主动说话提醒；点击身体随机触发砂金猫猫台词。
- **拖拽文件秒改名**：
  - 将任意文件（如 `000.jpg`，支持多文件批量拖入）直接拖到桌宠身上；
  - 在弹出的输入框中输入后缀（如 `555` 或 `（555）`）并按回车；
  - 自动在原文件所在目录重命名为 `000（555）.jpg`（支持切换全角/半角括号或无括号直接追加）。
